# 🚀 Applied Data Science Capstone Project

This repository contains all work completed as part of the **Applied Data Science Capstone** from IBM/Coursera.  
The project includes data collection, data wrangling, exploratory analysis, visualization, SQL analysis, dashboards, maps, and predictive modeling.

---

## 📁 Repository Structure


Each module contains the notebooks/scripts required for the capstone project tasks.

---

## 📌 Project Overview

The objective of this capstone is to apply the full workflow of data science:

- ✔ Data collection from web and APIs  
- ✔ Data wrangling and cleaning  
- ✔ Exploratory Data Analysis (EDA)  
- ✔ SQL-based analysis  
- ✔ Interactive visualizations  
- ✔ Geospatial map using **Folium**  
- ✔ Interactive dashboard using **Plotly Dash**  
- ✔ Predictive modeling (Regression)  
- ✔ Predictive modeling (Classification)  
- ✔ Insights and conclusions  

---

## 📊 Module Descriptions

### **📂 Module 1 — Data Collection**
- Collecting data using **web scraping**
- Collecting data using **REST APIs**
- Parsing HTML tables with Pandas

---

### **📂 Module 2 — Data Wrangling**
- Data cleaning  
- Formatting columns  
- Handling missing values

---

### **📂 Module 3 — Exploratory Data Analysis**
- EDA with **Matplotlib** and **Seaborn**  
- SQL queries using Pandas/SQLite

---

### **📂 Module 4 — Predictive Analysis**
- Predicting outcomes using **Logistic Regression / Classification Models**
- Building machine learning pipelines  
- Evaluating accuracy, precision, recall
